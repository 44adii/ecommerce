# Ecommerce Intelligence System

An end-to-end data analytics project focused on e-commerce customer behavior, revenue analysis, and churn prediction. This project combines SQL for data extraction, Python for predictive modeling, and Power BI for visual storytelling.

## 📊 Dashboard Overview
The core of this project is the **Ecommerce Intelligence Dashboard**. It provides actionable insights into:
- **Revenue Trends**: Monthly and quarterly growth analysis.
- **Customer Segmentation**: RFM (Recency, Frequency, Monetary) analysis.
- **Churn Prediction**: Identifying at-risk customers using machine learning.
- **Cohort Analysis**: Understanding customer retention over time.

> [!NOTE]
> To view the dashboard, download the `Ecommerce_Intelligence_Dashboard.pbix` file and open it in Power BI Desktop.

---

## 🛠️ Tech Stack
- **Database**: SQL (PostgreSQL/MySQL)
- **Programming**: Python (Pandas, Scikit-learn)
- **Visualization**: Power BI
- **Version Control**: Git

## 📂 Project Structure
- `sql/`: Complex queries for revenue and cohort analysis.
- `python/`: Scripts for data generation, RFM analysis, and churn prediction.
- `Ecommerce_Intelligence_Dashboard.pbix`: The main Power BI dashboard.
- `data/`: Sample datasets used for analysis.

## 🚀 How to Run
1. **Database Setup**: Execute scripts in `/sql` to prepare the data environment.
2. **Python Analysis**: Run `python/customer_segmentation.py` for RFM analysis.
3. **Visualization**: Open the `.pbix` file in Power BI and refresh the data source connections.
